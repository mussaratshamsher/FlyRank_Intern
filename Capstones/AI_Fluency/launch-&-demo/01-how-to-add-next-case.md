# How to Add My Next Portfolio Case Study

## Purpose

My portfolio should continue to demonstrate new, real work rather than remain a one-time project. I will use the same simple case-study structure for every new project.

## Three-Beat Case Study

1. **Problem** — What real problem did the project solve, and who was it for?
2. **What I Did** — What did I design, build, test, and improve? Include the important AI/backend engineering decisions.
3. **What Came of It** — What was delivered, what worked, what was learned, and what measurable or practical impact resulted?

## Steps to Add the Next Case

1. Open my existing portfolio project section.
2. Duplicate the existing case-study structure so the visual style remains consistent.
3. Add the project title and one-sentence description.
4. Write the **Problem → What I Did → What Came of It** sections.
5. Add the most useful evidence: live demo, GitHub repository, screenshots, architecture, or results.
6. Review the case study for clarity, technical accuracy, and concise storytelling.
7. Publish the update and verify the live page and links.
8. Keep the source/project context in my Claude Project so future portfolio updates do not require rebuilding the context from scratch.
