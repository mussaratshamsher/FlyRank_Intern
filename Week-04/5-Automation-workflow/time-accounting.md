# Time Accounting — Honest Manual vs Workflow

## Setup cost (one-time, first build)
| Item | Time |
|------|------|
| Create NotebookLM notebook + add sources (first run) | ~15 min |
| Create Claude Project + load instructions + prompts | ~15 min |
| **Setup total** | **~30 min** |

## Per-run timing (measured across the five runs)
| Step | Tool | Workflow time |
|------|------|---------------|
| 1. Gather | NotebookLM | ~6–10 min |
| 2. Synthesize | NotebookLM | ~3–5 min |
| 3. Draft | Claude Project | ~2–3 min |
| 4. Critique | Claude Project | ~1–2 min |
| 5. Format | Claude Project | ~1–2 min |
| **Workflow subtotal** | | **~13–22 min** |

## Manual baseline (doing the same brief by hand)
Manually, the same weekly brief involves:
- Reading 4–6 articles and taking notes: ~25–35 min.
- Writing a structured draft: ~20–25 min.
- Self-reviewing for accuracy/tone: ~10–15 min.
- Formatting with links and word count: ~8–10 min.
- **Manual total** | | **~63–85 min** (~1.1–1.4 hours)

## Time-saved estimate
- Workflow: ~15–20 min per run (midpoint).
- Manual: ~70 min per run (midpoint).
- **Saved: ~50 min per brief → roughly 3× faster.**
- Across 5 runs: ~250 min saved (~4 hours).
- After the one-time 30-min setup, the 5th run alone already pays back the setup cost.

## Honest caveats
- The 30-min setup is real and must be counted — it is not free "time saved."
- Gather (step 1) is the least automated part: I still curate sources and sanity-check them.
- The timings assume sources are already identified. If research starts from a blank page, add ~10 min to gather.
- I did not skimp on the critique step — it runs every time, even when the answer is "no revisions needed."
