# Identity Kit — Mussarat Shamsher

**Role:** Software Engineer · AI Developer

## Brand Palette
| Colour | Hex | Usage |
|--------|-----|-------|
| Charcoal | `#2D3436` | Text / primary content |
| Off-white | `#F8F9FA` | Background |
| Purple | `#6C5CE7` | Primary / brand / links / actions |
| Teal | `#A0D2DB` | Secondary / backgrounds / dividers |

## Typography
- **Headings:** Playfair Display (weights 600/700)
- **Body:** Inter (weights 300/400/500)

## Mark
- **MS monogram** in a rounded purple badge (SVG favicon + header logo).
- Variants: Primary (purple), Dark (charcoal), Outline (purple stroke).

## Usage Guidelines
- Always use Playfair Display for headings.
- Purple `#6C5CE7` for primary actions & links.
- Teal `#A0D2DB` for backgrounds & dividers.
- Maintain generous whitespace.
