# Week 01 — Workflow Audit

## Project objective

Document how tasks were approached using AI assistance (and where human judgment was used), and validate outcomes against the defined target tasks.

## What you learned

- AI can accelerate implementation for structured work (e.g., drafting and iteration), but correctness still requires verification.
- When debugging, AI can help identify likely causes quickly, while final fixes must be tested to confirm there are no runtime errors.
- For content tasks (like LinkedIn posts), AI is effective for drafting, but tone and quality are improved through review and editing.
- Research tasks benefit from a comparison mindset (pros/cons across multiple options) and a clear recommendation at the end.

## Folder contents

- `workflow-audit.md`: AI classification and rationale per workflow task (what used AI, what was human-only, and why).
- `target-task.md`: Success criteria for the target tasks, including:
  - Writing LinkedIn posts (SEO, <300 words, professional tone, no grammar mistakes)
  - Debugging Python (bug fixed, code tested, no runtime errors)
  - Research AI frameworks (compare at least 3, pros/cons, recommendation)
- `screenshots/`: Evidence/visuals captured during the work.
  - `AI-Fluency.png`
  - `claude-project.png`
